# ChickenJoo Website — Requirements

## Overview
A responsive website for ChickenJoo, a Korean chicken restaurant, to promote the
business and give customers a central source of restaurant info. Includes an
admin interface for managing published content.

## Customer-Facing Features
- Restaurant promotion (home/landing content, menu offerings, branch locations, contact details)
- Blog/news page
- Ordering page (deliberately last — may be complex, scope TBD when we reach it)

## Admin-Facing Features
- Authentication / access control for authorized staff only
- Content management for news/blog posts
- Ability to keep menu, promotions, and branch info accurate and up to date

## Non-Goals (explicitly out of scope for now)
- Online payment gateway integration
- Third-party delivery platform integration
- Advanced/expanded ordering workflows beyond a simple order request
- Advanced customer engagement features beyond what's listed above

## Build Order
1. Project scaffold + design system (mobile-first, per UI inspo)
2. Static customer-facing pages (promotion/home, branches/contact)
3. Blog/news page (static/placeholder data first, no CMS yet)
4. Admin auth + CMS for content
5. Ordering (last)
